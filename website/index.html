getapk is a plugin for Claude Code. Run /getapk with a Google Play link and Claude fetches the app's APK and hands the file to you in the conversation, with nothing saved in your project folder.

Install the pluginView source 
/getapk https://play.google.com/store/apps/details?id=com.whatsapp

How it works

  1. You give a link

    Any play.google.com/store/apps/details?id=… link, or just a package id like com.whatsapp. The plugin reads the id= value.

  2. It picks a method

    First it tries adb on a connected phone or emulator. If the app isn't there, it falls back to a mirror download.

  3. It checks the file

    The result must be a real APK (a valid zip with an AndroidManifest.xml), otherwise it is discarded.

  4. It sends it to you

    The file is staged in your system temp folder and attached to the chat. Your repo stays clean.

adb

Runs adb shell pm path then adb pull. Most reliable, and handles split APKs. Needs the app installed on a device with USB debugging on.

mirror

Downloads the latest APK of a free app from APKPure's public endpoint. No phone needed.

Install

Run these in your own terminal (Python 3 required):

git clone https://github.com/divyanshugour/getapk
claude --plugin-dir ./getapk

Inside Claude Code, type /help and check that /getapk is listed. It may appear as /getapk:getapk.

Usage

/getapk <play-store-link> [--method auto|adb|mirror] [--out DIR]
OptionWhat it does
--method autoDefault. adb first, then the mirror.
--method adbOnly pull from a connected device.
--method mirrorOnly download from the mirror (free apps).
--out DIRStage files in DIR instead of the temp folder.

You can also run the script directly: python3 scripts/getapk.py <link>

Chat delivery works where Claude Code can attach files (the web and app). In a plain terminal, Claude shows the temp file path instead.

FAQ

Why did the download fail?

The app is probably paid, region-locked or removed, so the mirror can't serve it. Use the adb method with a device that has the app installed.

What is a split APK?

Some apps ship as a base APK plus config splits. adb saves them all; install them together with adb install-multiple.

Is the mirror version the same as Play Store's?

It is the latest version the mirror holds, which can lag behind Play Store. adb gives you exactly what is on your device.

Does it work for paid apps?

No. The plugin is not meant to get around payment, licensing or DRM.

Use it responsibly

Only extract apps you have the right to copy: your own apps, free apps, or software you are permitted to analyse. Third-party mirrors are outside this project's control, and APKs from any source should be scanned before you install them.
